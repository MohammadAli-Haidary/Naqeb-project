## 📋 درباره پروژه

**امپریال تکنالوژی** یک سیستم یکپارچه برای مدیریت فروشگاه‌های کمپیوتر و تجهیزات جانبی است. این سیستم تمام عملیات روزمره فروشگاه شامل خرید، فروش، انبار، حسابداری، تعمیرات و ضمانت را در یک محیط منظم و کاربرپسند مدیریت می‌کند.

### ✨ ویژگی‌های اصلی

- 🛒 **مدیریت فروش** - POS سریع با پشتیبانی از بارکد
- 📦 **مدیریت انبار** - ردیابی موجودی و دستگاه‌های سریال‌دار
- 💰 **حسابداری دوطرفه** - ثبت دقیق تمام تراکنش‌های مالی
- 🔧 **مدیریت تعمیرات** - پیگیری سفارش‌های تعمیر و ضمانت
- 📊 **گزارش‌های مدیریتی** - تحلیل فروش، سود، موجودی و بدهی‌ها
- 🗄️ **دیتابیس SQLite** - ذخیره‌سازی محلی و امن
- 🌐 **پشتیبانی کامل** - زبان دری/فارسی، تقویم شمسی، واحد افغانی

---

## 🚀 شروع سریع

### حالت ۱: اجرای دمو (مرورگر)

برای مشاهده دمو در مرورگر:

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev
```

سپس مرورگر را باز کنید: `http://localhost:5173`

> ⚠️ **توجه:** در این حالت از `localStorage` استفاده می‌شود و داده‌ها دائمی نیستند.

### حالت ۲: اجرای کامل (Electron + SQLite)

برای استفاده واقعی در فروشگاه:

```bash
# ۱. نصب پکیج‌های Electron
npm install --save-dev electron electron-builder
npm install --save better-sqlite3
npm install --save-dev @types/better-sqlite3 concurrently wait-on

# ۲. اجرای برنامه
npm run electron:dev
```

📖 **راهنمای کامل:** فایل `ELECTRON_SETUP.md` را مطالعه کنید یا از منوی "راهنمای نصب SQLite" در برنامه استفاده کنید.
